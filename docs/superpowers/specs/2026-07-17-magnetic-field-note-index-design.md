# 文章列表「磁场卡片」改版设计

## 目标

将首页现有的等高文章索引改造成已确认的方案 C「磁场卡片」：通过不同尺寸、错位起点和大面积留白形成自然的内容场，让文章列表更轻盈、更有主次，同时保持当前极简黑白灰、少量钴蓝的整体风格。

本次只调整文章列表的展示结构与交互反馈，不改变首页其他版式、路由、搜索、分类、管理员操作、密码验证或接口数据。

## 设计结论

- 桌面端使用十二列 CSS Grid，将文章按稳定的六项节奏分配为主卡、横卡、小卡、紧凑卡、竖卡和收束卡。
- 卡片阅读顺序始终与 DOM 顺序一致；尺寸变化只负责建立视觉层级，不重新排序数据。
- 主卡突出当前列表第一篇文章，其余卡片通过面积、纵向错位和留白形成磁场感。
- 卡片保持近白半透明表面、细灰边框和较大但克制的圆角；不使用持续发光、大渐变或厚重阴影。
- 钴蓝只用于首项标识、焦点边框、箭头反馈和极淡环境光，不改变现有主题主色。
- 移动端回归单列卡片，仅保留少量左右缩进差异，避免横向滚动与阅读顺序混乱。

## 信息结构

每张文章卡片包含：

1. 两位序号。
2. 分类名称，缺失时显示“未分类”。
3. 修改日期。
4. 文章标题。
5. 受保护状态图标。
6. 进入详情的右上箭头。
7. 已登录管理员可见的管理菜单。

列表接口继续只消费 `NoteSummary`。卡片不得请求、预取或渲染正文；点击受保护文章仍执行现有密码验证流程，验证成功后才进入详情页。

## 布局节奏

### 桌面端

每六项构成一个视觉组，使用组件生成的语义修饰类控制网格位置：

- 第 1 项：左侧主卡，占六列和较大高度。
- 第 2 项：右侧横卡，占六列，起点下沉一行。
- 第 3 项：左侧中卡，占四列。
- 第 4 项：中部紧凑卡，占三列并继续下沉。
- 第 5 项：右侧竖卡，占四列和较大高度。
- 第 6 项：左侧收束横卡，占七列。

后续组复用相同尺寸节奏，但可通过奇偶组镜像部分起点，避免大量文章时形成机械重复。布局必须自动扩展，不依赖文章总数；不足六项时不出现空白占位节点。

### 平板与移动端

- `900px` 以下取消十二列定位，切换为单列文档流。
- 主卡高度略大，其他卡片使用内容驱动的最小高度。
- 个别卡片最多保留约 `6%–12%` 的左右缩进，且任何卡片宽度不得超出容器。
- 管理菜单保持可触达，不依赖悬停才显示。

## 交互与动效

- 鼠标悬停或键盘聚焦时，卡片上移约 `4–6px`，边框变为低透明度钴蓝，并出现极弱阴影。
- 奇偶卡片允许约 `0.3deg` 的反向微旋转，制造轻微磁吸感；移动端关闭旋转。
- 箭头同时向右上移动约 `3px` 并变为钴蓝。
- 每张卡片右上角可出现小范围、低透明度的蓝色径向光，只在悬停或聚焦时显现。
- 所有反馈控制在约 `180–280ms`，使用平滑缓动。
- `prefers-reduced-motion: reduce` 时关闭位移、旋转和装饰光移动，只保留边框与颜色状态。

## 可访问性

- 每张卡片的主点击区域继续使用原生 `button`，支持 Enter 和 Space。
- 管理菜单保留独立按钮，不能嵌套进文章主按钮，也不能触发文章跳转。
- `:focus-visible` 必须具有清晰的钴蓝焦点轮廓。
- 锁图标保留“已加密”的可访问标签；箭头继续标记为装饰元素。
- 视觉错位不得使用会改变屏幕阅读器顺序的 CSS `order`。
- 文字和边框在白天环境下保持足够对比度。

## 组件改动

### `src/app/components/NoteIndex.tsx`

- 为根节点增加磁场网格语义。
- 根据索引计算六种卡片变体与视觉组奇偶状态。
- 将现有行式信息重组为卡片头部、标题区和箭头。
- 保留 `isNoteLocked`、`onSelect` 与 `renderActions` 的现有组件契约。
- 继续用 `Reveal` 执行首次入场，不引入新的动画依赖。

### `src/styles/index.css`

- 用十二列磁场网格替换 `.note-index-row` 的等高横行样式。
- 新增卡片变体、悬停/聚焦、管理员菜单和响应式规则。
- 保留全站主题令牌，不新增远程字体、图片或大型视觉依赖。

### 测试

- 新增一个纯函数，将任意索引映射为稳定的卡片变体和组方向；用 Node 测试覆盖前两组及循环边界。
- 组件只消费映射结果，避免在 JSX 中散落位置判断。
- 现有密码流程、列表摘要契约和路由测试必须保持通过。

## 边界与异常状态

- 只有一篇文章时显示一张主卡，不拉伸到夸张高度。
- 长标题允许自然换行，并为管理菜单和箭头保留安全区。
- 长分类名截断为单行并保留完整 `title` 提示。
- 搜索或分类筛选后，当前结果集从第一项重新计算视觉节奏。
- 空状态维持现有处理，不渲染磁场网格。
- 管理员菜单打开时卡片保持当前层级，不被邻近卡片遮挡。

## 验收标准

- 桌面端文章列表与方案 C Demo 的疏密、主次、错位和克制科技感一致。
- 首页其他版式、搜索、分类、导出、设置和粒子效果不发生结构变化。
- 普通文章点击直接进入详情；受保护文章仍先验证密码，成功后进入详情。
- 列表网络响应不包含文章正文或密码。
- 360px、768px、1024px 和宽屏下均无横向滚动、重叠或不可点击区域。
- 键盘可完整操作文章入口与管理员菜单，减少动态效果偏好生效。
- `pnpm test` 与 `pnpm build` 全部通过。

## 非目标

- 不改首页 Hero、导航、搜索框、分类栏或详情页版式。
- 不修改服务端、API 契约、数据结构、同步、导出、认证或密码逻辑。
- 不新增图片素材、远程资源、第三方卡片库或新的运行时依赖。
- 不增加主题切换、深色模式或用户自定义布局。
