# 安全笔记摘要与详情访问设计

## 目标

首页只加载文章摘要并显示单列文章索引。点击普通文章直接进入详情；点击受笔记密码或分类密码保护的文章时，必须先完成服务端密码验证，验证成功后才能跳转。任何列表、筛选或同步响应都不得携带正文与真实密码。

## 列表摘要契约

`GET /api/notes` 与 `POST /api/sync` 返回统一摘要对象：

```json
{
  "id": "note-id",
  "title": "标题",
  "createTime": 0,
  "modifyTime": 0,
  "folder": "分类",
  "noteProtected": true,
  "folderProtected": false
}
```

摘要不得包含 `content`、`password` 或分类密码。搜索范围收窄为标题和分类；首页不再支持正文全文搜索。

## 首页交互

- 移除桌面端右侧文章预览，所有断点均只显示文章索引。
- 普通文章点击后直接导航到 `/note/:id`。
- 分类受保护时先验证分类密码；笔记受保护时再验证笔记密码；两者都存在时按分类、笔记顺序完成两次验证。
- 验证失败时停留在列表，显示现有错误与防爆破提示。
- 验证成功后才执行路由跳转。
- 管理员已登录时允许直接进入详情，但不改变普通访客流程。

## 解锁会话

- `/api/password/verify` 验证成功后，将对应的 `folder:<name>` 或 `note:<id>` 授权写入服务端解锁会话。
- 解锁会话通过 `HttpOnly`、`SameSite=Lax` Cookie 标识，默认 30 分钟失效，并绑定客户端 IP。
- Cookie 只保存随机会话 ID；授权范围、过期时间和 IP 保存在服务端内存中。
- 每次验证成功刷新会话过期时间；无效或过期会话按未解锁处理。
- 现有密码错误次数限制继续生效。

## 详情接口

- 新增 `GET /api/notes/:id/summary`，用于直接访问详情网址时读取单篇摘要。
- `GET /api/notes/:id` 只在以下任一条件成立时返回正文：文章不受保护；管理员会话有效；解锁会话包含该文章需要的全部分类与笔记授权。
- 未满足授权时返回 HTTP `423`，响应只包含摘要和仍需验证的作用域，不包含正文或密码。
- 成功详情响应删除 `password` 字段，只返回展示所需数据。
- 详情页直接打开时先获取摘要，根据保护标识依次弹出密码框；验证完成后再请求正文。

## 设置与密码保密

- 公共设置响应不再返回真实分类密码，只返回受保护分类名称。
- 管理员设置页通过受管理员 Session 保护的 `GET /api/admin/settings` 获取可编辑的真实设置。
- 现有站点访问密码行为本次不改；本次范围只封闭文章正文、笔记密码和分类密码泄露路径。

## 同步、更新与导出

- 同步仍将完整正文保存到服务端本地，但响应只返回摘要数组。
- 笔记更新响应返回更新后的摘要，首页不接收正文。
- 导出按钮仅对已认证管理员显示，并通过 `GET /api/admin/notes/export` 获取完整数据；普通列表接口不承担导出正文。
- 导出响应不得改变服务器存储，也不包含分类密码或站点设置。

## 前端模型

- `Note` 拆分为 `NoteSummary` 与 `NoteDetail`。摘要没有 `content` 与 `password`。
- `HomePage` 只保存 `NoteSummary[]`。
- `NotesList` 删除桌面预览、正文截断和基于正文的搜索，不再读取 `NoteContent`。
- `NoteDetailPage` 使用摘要驱动解锁，再获取 `NoteDetail` 渲染正文。
- 不再依赖 localStorage 中的解锁 ID 作为访问授权；服务端 HttpOnly 会话是唯一授权来源。

## 测试与验收

- 单元测试覆盖摘要字段白名单、密码字段剔除、解锁会话授权/过期/IP 绑定与必需作用域判断。
- 接口测试覆盖列表不含正文、同步不含正文、受保护详情返回 423、验证后返回正文、管理员绕过和导出鉴权。
- 前端构建必须成功，现有测试必须全部通过。
- 手工验证普通文章跳转、分类密码、笔记密码、双重密码、错误密码、直接详情网址、刷新详情、管理员访问和导出。
- 验收时浏览器网络面板中的列表与同步响应不得出现正文内容或真实密码。

## 非目标

- 不改变本地 `notes.json` 存储格式。
- 不改变小米云同步来源与图片缓存逻辑。
- 不在本次重构站点总访问密码。
- 不新增数据库或持久化解锁会话；服务重启后访客需要重新解锁。
