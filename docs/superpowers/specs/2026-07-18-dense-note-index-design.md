# 文章列表紧凑无序网格设计

## 目标

缩小当前文章卡片，增加同屏信息密度，并将桌面端列表改为具有明显无序感的紧凑网格。列表按 `3 个 → 4 个 → 2 个` 的行节奏循环，每行内部使用不等宽卡片；卡片高度完全由标题内容决定，不再使用大面积固定高度。

本次只调整文章列表的排布和卡片尺寸，不修改首页其他区域、文章数据、搜索分类、密码验证、管理员操作或详情跳转。

## 排布模型

文章按当前筛选结果的 DOM 顺序依次分组：

- 第 1 行放 3 篇，十二列跨度为 `5 / 3 / 4`。
- 第 2 行放 4 篇，十二列跨度为 `2 / 4 / 3 / 3`。
- 第 3 行放 2 篇，十二列跨度为 `7 / 5`。
- 后续继续按 `3 → 4 → 2` 循环。

每个完整循环包含 9 篇文章。奇数循环使用上述跨度，偶数循环左右镜像：

- 3 篇行变为 `4 / 3 / 5`。
- 4 篇行变为 `3 / 3 / 4 / 2`。
- 2 篇行变为 `5 / 7`。

不足一整行时只渲染实际文章，不创建占位卡片；剩余卡片沿用当前行的前几个跨度，并保持左对齐或镜像后的右对齐。

## 卡片尺寸与视觉

- 卡片取消当前 `7rem–10.5rem` 的固定最小高度。
- 普通卡片使用约 `0.75rem–0.85rem` 内边距，最低高度只保证标题、元信息和箭头可用，约 `66px`。
- 标题自然换行并撑高卡片，不设置统一行高、不截断标题。
- 同一行使用 `align-items: start`，因此短标题卡片和长标题卡片底边可以不齐，形成自然错落。
- 每行卡片按确定性序列增加 `0–10px` 的轻微顶部偏移，打散连续边线；偏移不使用随机数。
- 卡片圆角收窄至约 `0.8rem–0.9rem`，边框、近白表面和钴蓝焦点反馈沿用当前主题。
- 去掉夸张的主卡标题尺寸；所有标题保持接近的字号，只允许窄卡略小，避免单张卡片重新成为大面积视觉块。
- 保留当前轻微上浮、微旋转和箭头位移动效，但悬停上浮缩小至约 `3px`，避免密集网格中相邻卡片碰撞。

## 组件与数据边界

### 布局辅助函数

在 `src/app/lib/noteIndex.js` 中用纯函数描述行节奏：

- `getNoteRowLayout(rowIndex)` 返回该行数量、十二列跨度和镜像方向。
- `groupNotesByRowPattern(notes)` 按 `3 / 4 / 2` 循环分组，并保留原始绝对索引。

纯函数必须对空数组、不足一行、多循环和筛选后的新数组给出稳定结果。

### `NoteIndex`

- 使用行分组结果渲染 `.note-index-row-group`。
- 每张卡片通过 CSS 自定义属性或语义类获得列跨度。
- 编号继续使用筛选结果中的绝对索引。
- `isNoteLocked`、`onSelect` 和 `renderActions` 组件契约保持不变。
- 不读取、请求或预取文章正文。

### 样式

- 桌面端每行独立使用十二列 CSS Grid，避免跨行固定高度。
- 行间距明显小于当前磁场分组间距，形成连续内容流。
- 卡片自身不拉伸到所在网格行高度，使用内容自适应高度。
- 管理员菜单继续位于卡片右上角，并为标题与元信息预留安全区。

## 响应式

- `1100px` 以上使用完整 `3 → 4 → 2` 模式。
- `720px–1099px` 将每行降为 2 列，但继续使用 `5 / 7`、`7 / 5` 交替宽度。
- `719px` 以下回归单列，保留轻微的 `92%–100%` 宽度错位。
- 所有断点保持 DOM 顺序，不使用 CSS `order`。
- 页面不得出现横向滚动；分类栏原有的横向滚动行为不在本次范围。

## 交互与可访问性

- 卡片主入口继续使用原生 `button`，支持键盘 Enter 和 Space。
- 管理员菜单保持独立按钮，不嵌套在文章按钮内。
- 锁定图标继续提供“已加密”标签。
- 键盘焦点使用清晰钴蓝轮廓。
- `prefers-reduced-motion: reduce` 时取消位移和旋转，只保留边框与颜色反馈。
- 视觉宽度和高度变化不得改变屏幕阅读器顺序。

## 测试与验收

- 单元测试覆盖前两个完整循环的行数量、跨度、镜像方向和绝对索引。
- 现有文章摘要、受保护文章跳转和密码流程测试必须保持通过。
- Vite 生产构建必须成功。
- 桌面端至少用 13 篇文章验证 `3 / 4 / 2 / 3 / 1` 的实际分组。
- 在 `1440px`、`1024px`、`768px` 和 `390px` 验证无卡片重叠、无页面横向溢出。
- 长标题必须完整展示并自然撑高，短标题卡片不得被强制拉到同高。

## 非目标

- 不改首页 Hero、搜索、分类栏、粒子、导航、页脚或详情页。
- 不修改服务端、API 契约、同步、导出、密码或路由逻辑。
- 不采用 CSS Columns 瀑布流、实验性 CSS Masonry 或随机数排布。
- 不新增依赖、远程资源、主题切换或深色模式。
